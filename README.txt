FREE WEDDING INVITATION WEBSITE

1) Open index.html in any browser.
2) Search for CONFIG near the bottom of index.html.
3) Replace Groom, Bride, date/time, venue, map link, and message.
4) Optional: put music.mp3 inside assets/ and set musicUrl to 'assets/music.mp3'.
5) To add your photos, replace the two photo-placeholder <div> blocks with <img> tags, for example:
   <img src="assets/photo1.jpg" alt="Couple photo" style="width:100%;border-radius:28px;display:block">

FREE PUBLISHING WITH GITHUB PAGES
- Create a free GitHub account.
- Create a new repository.
- Upload index.html and the assets folder.
- Go to Settings > Pages.
- Under Build and deployment, choose Deploy from a branch, then main / root.
- GitHub will give you a free public link.

The design uses Google Fonts. The invitation background image is included locally in assets/invitation-bg.png.
